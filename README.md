# js_playground

Test and learning space for JavaScript and React, covering everything from vanilla JS practice scripts to small React apps.

## 📁 Project Structure

| Folder | Description |
|---|---|
| `api-practice` | Exercises working with external APIs (fetch requests, handling responses, etc.) |
| `db_simple_storage` | Simple data storage / persistence experiments |
| `front_1` | Early front-end practice project |
| `js_async_test` | Practice with asynchronous JavaScript — Promises, `async`/`await` |
| `login_window` | A login window / form UI exercise |
| `my-react-dashboard` | A React-based dashboard project |
| `react_test` | General React practice and component experiments |
| `simple_calculator` | A basic calculator app |

> Each folder is a self-contained mini-project — check inside for its own setup if needed.

## 🚀 Getting Started

Clone the repo:

```bash
git clone https://github.com/demydev/js_playground.git
cd js_playground
```

Install dependencies:

```bash
npm install
```

Then navigate into the specific project folder you want to run and follow any instructions there (e.g. `npm start` for React-based folders, or open `index.html` for plain JS/HTML projects).
